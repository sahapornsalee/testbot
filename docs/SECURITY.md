# ความปลอดภัยและความเป็นส่วนตัว

## ขอบเขต
เว็บ static ไม่มี backend ไม่มีระบบสมาชิก ไม่มี analytics และไม่มีการเรียก API ภายนอก ข้อมูลผู้ใช้อยู่ใน LocalStorage ของเบราว์เซอร์เท่านั้น

## มาตรการปัจจุบัน
- ไม่มี API key, token หรือ secret ใน source code
- ไม่ใช้ `eval`, `new Function` หรือ `dangerouslySetInnerHTML` — เครื่องคิดเลขใช้ parser ที่รับเฉพาะตัวเลขและเครื่องหมายที่อนุญาต
- ข้อมูลจาก LocalStorage ถือว่าไม่น่าเชื่อถือ: ตรวจ version และชนิดข้อมูลทุกครั้ง ข้อมูลเสียหายใช้ค่าเริ่มต้น
- Route parameter รับเฉพาะ `[a-z0-9-]`
- ErrorBoundary log เฉพาะข้อความ error ไม่ log ข้อมูลผู้ใช้
- GitHub Actions: สิทธิ์เริ่มต้น `contents: read`; เฉพาะ job deploy ได้ `pages: write` และ `id-token: write` และ deploy เฉพาะจาก `main`

## ข้อจำกัดที่ต้องเข้าใจ
LocalStorage ไม่ได้เข้ารหัส สคริปต์อันตรายหรือส่วนขยายเบราว์เซอร์อาจอ่านได้ และข้อมูลอาจถูกล้างโดยเบราว์เซอร์ อย่าใช้บนอุปกรณ์สาธารณะสำหรับข้อมูลสำคัญ

## งานที่ต้องทำเมื่อมี Import/Export (Phase 2)
ตรวจชนิดไฟล์ ขนาดไฟล์ โครงสร้างและ version ก่อนนำเข้า ห้ามรันสคริปต์จากไฟล์นำเข้า และสำรองข้อมูลก่อน migration

## การรายงานปัญหา
เปิด issue ใน repository โดยไม่ใส่ข้อมูลส่วนตัว
