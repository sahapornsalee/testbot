# ข้อกำหนดระบบ (Requirements)

เอกสารนี้เป็นแหล่งอ้างอิงหลักของขอบเขตงาน AI และผู้พัฒนาต้องไม่สร้างฟีเจอร์นอกขอบเขตโดยพลการ

## หลักการสำคัญ

- ไม่ต้องสมัครสมาชิกเพื่อใช้เครื่องมือพื้นฐาน
- ไม่ต้องตั้งค่า API Key หรือบริการภายนอกสำหรับฟีเจอร์หลัก
- ข้อมูลส่วนตัวเก็บในเบราว์เซอร์ของผู้ใช้เป็นหลัก
- ทุกฟีเจอร์ต้องมีสถานะโหลด ว่าง สำเร็จ และผิดพลาดอย่างเหมาะสม
- AI เป็นผู้ช่วยเขียนโค้ด ไม่ใช่ส่วนบังคับในการใช้งานเว็บ
- การเปลี่ยนแปลงโค้ดต้องตรวจสอบและทดสอบก่อนนำขึ้นเว็บไซต์จริง

## ข้อกำหนดด้านคุณภาพ

- **Responsive**: ใช้งานได้บนมือถือ แท็บเล็ต และคอมพิวเตอร์
- **Performance**: ไม่โหลดเครื่องมือทุกตัวพร้อมกันหากไม่จำเป็น (lazy loading)
- **Reliability**: ข้อมูลไม่หายเมื่อเปลี่ยนหน้า และวิดเจ็ตที่ผิดพลาดต้องไม่ทำให้ทั้งหน้าพัง
- **Maintainability**: แยกแต่ละเครื่องมือออกจากกัน
- **Privacy**: ข้อมูลไม่ถูกส่งออกนอกอุปกรณ์โดยไม่มีการกระทำที่ชัดเจนจากผู้ใช้
- **Accessibility**: เป้าหมาย WCAG 2.2 AA
- **Portability**: สำรองข้อมูลเป็นไฟล์ที่เก็บไว้นอกเบราว์เซอร์ได้

## ขอบเขตที่ไม่รวมในเวอร์ชันแรก

ระบบสมาชิกออนไลน์ การซิงก์ข้ามอุปกรณ์ การส่งอีเมล การแจ้งเตือนผ่านเซิร์ฟเวอร์ และการเรียก AI API จากเว็บโดยตรง
